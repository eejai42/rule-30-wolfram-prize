# Primary sources and retrieval scope

Sources consulted 2026-10-22. Mutable URLs record the retrieved state, not a guarantee about later versions.

1. Wolfram Foundation, [Rule 30 Prizes](https://rule30prize.org/). Prize statements, full-proof requirement, reproducibility and guidelines.
2. Stephen Wolfram, [Announcing the Rule 30 Prizes](https://writings.stephenwolfram.com/2019/10/announcing-the-rule-30-prizes/), 2019. Formal Statements, complexity discussion, empirical count table and adjacent-column background. The displayed complexity predicate and prose differ as explained in the report.
3. WolframInstitute, [Rule30PrizeKit README](https://github.com/WolframInstitute/Rule30PrizeKit/blob/main/README.md) and [Rule30Prize.lean](https://github.com/WolframInstitute/Rule30PrizeKit/blob/main/lean/Ruliology/CellularAutomata/Rule30Prize.lean). Read via GitHub. Existing period-one exclusion; no official Problem 3 Lean statement. The project was not installed or run. These files are references, not a certificate that our proofs were kernel checked.
4. EJ Alexandra, [CMCC as a Universal Computational Framework](https://doi.org/10.5281/zenodo.14760293), January 2025. Entire PDF downloaded and text read. Retained as `sources/cmcc-foundations.pdf` with extracted text. Sections 2, 3, 4 and 6 are the principal mathematical sources. The repository links an obsolete filename; the actual Zenodo filename starts `PAPER_ The Conceptual...`.
5. EJ Alexandra, [BRCC and Its Proof Sketch](https://doi.org/10.5281/zenodo.14759299), January 2025. Entire PDF read; retained as `sources/brcc-proof.pdf` and text. Despite the filename containing “3page”, the retrieved document includes a cover and contents plus six numbered pages.
6. [CMCC repository](https://github.com/eejai42/conceptual-model-completeness-conjecture-toe-meta-model), tree commit `1a3d4357fb92c50918112f27d2531f16d2742f05`. Root README and research index read; used to locate foundational sources. The many domain examples were not exhaustively audited.
7. Stephen Wolfram, [The Concept of the Ruliad](https://writings.stephenwolfram.com/2021/11/the-concept-of-the-ruliad/), 2021. Consulted sections defining the Ruliad, sampling, representation and computational universality. Used for conceptual context, not as a theorem provider.
8. EffortlessAPI, [Simpson's Paradox README](https://github.com/EffortlessAPI/effortless-rulebooks/blob/afe180c67cd8b0247c9b82ec72aa87e3654efd9a/rulebook-examples/simpsons-paradox/README.md) and [conclusion answer keys](https://github.com/EffortlessAPI/effortless-rulebooks/blob/afe180c67cd8b0247c9b82ec72aa87e3654efd9a/rulebook-examples/simpsons-paradox/testing/answer-keys/conclusions.json). Read the README and relevant correction entries, especially conc-17 and conc-32. Not an independent audit of the corpus or theorem labels.
9. EffortlessAPI, [Effortless Math README](https://github.com/EffortlessAPI/effortless-rulebooks/blob/afe180c67cd8b0247c9b82ec72aa87e3654efd9a/rulebook-examples/effortless-math/README.md), [Trust Model](https://github.com/EffortlessAPI/effortless-rulebooks/blob/afe180c67cd8b0247c9b82ec72aa87e3654efd9a/rulebook-examples/effortless-math/docs/TRUST_MODEL.md), and [FLT theorem contract](https://github.com/EffortlessAPI/effortless-rulebooks/blob/afe180c67cd8b0247c9b82ec72aa87e3654efd9a/rulebook-examples/effortless-math/domains/fermats-last-theorem/theorem-contract.json). Also inspected WITNESS_REPORT_V21.md. Its interpretation explicitly retains seven imported foundations. Its executable project and imported mathematics were not independently rerun or proved here.
