## The prize page (rule30prize.org)

The problems concern the infinite sequence of center-cell values in the pattern generated by
rule 30 evolving from a single nonzero cell.

Problem 1: Does the center column always remain non-periodic?

Problem 2: Does each color of cell occur on average equally often in the center column?

Problem 3: Does computing the nth cell of the center column require at least O(n)
computational effort?

## The 2019 announcement

The colors of the cells on the line below are determined by looking at each cell and its
immediate neighbors. With numerical cell values 0 and 1, the basic rule is just
Mod[p + q + r + q r, 2]. If you start with a single black cell, what will happen?

Formal statements:

    c[t_] := CellularAutomaton[30, {{1}, 0}, {t, {{0}}}]

    Problem 1: NotExists[{p, i}, ForAll[t, t > i, c[t + p] == c[t]]]

    Problem 2: DiscreteLimit[Total[c[t]]/t, t -> Infinity] == 1/2

    Problem 3: machine[m][n] gives {v, t}, where v is the output value and t is the amount of
    computational effort taken (e.g. number of steps). Is there a machine m that computes
    c[n] correctly for all n while keeping the limsup of t/n finite? The machine's rule
    cannot simply store the answer.

For definiteness we could say that we always want to do the computation on a Turing machine.
Presumably in a cellular automaton we'd want to count the total number of cell updates done.
Computational universality implies that, within some basic constraints, it ultimately
doesn't matter. Reducing the effort for the center column to less than O(n^2) would be a
nice partial result.

## The research problem statement (REPORT.md §1)

Let x(i,0) = [i = 0], with i an integer, and

    x(i, t+1) = x(i-1, t) XOR (x(i, t) OR x(i+1, t)).

Write c(t) = x(0, t), t >= 0. Problem 1 asks whether for every T >= 0 and p >= 1 there exists
t >= T with c(t+p) != c(t). Problem 2 asks whether the limit of N^-1 * sum_{t=0}^{N-1} c(t) is
1/2. The distinction between N values and an inclusive horizon T matters for finite counts.

Problem 3 has a wording issue: the prose discusses no sublinear algorithm, whereas the
displayed limsup(time(n)/n) < infinity predicate excludes O(n) algorithms. Any claim needs a
fixed uniform machine, a binary encoding of n, a finite program description, an explicit cost
model and the selected asymptotic quantifiers.

Known partial results used as anchors: the center column is not eventually constant (the
period-one case). If c(t) = 1 for every t in [T, V] then V <= 2T + 1; if c(t) = 0 throughout,
V <= 4T + 5 (Theorem D, constant center-run bounds).
